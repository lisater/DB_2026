#### Задание 1
Раздел «Instance» («Экземпляр БД») - управление сервером MySQL на уровне ОС (требует настройки SSH). Основные пункты:
1. Startup / Shutdown - запуск и остановка сервера, отображение статуса и лога запуска.
2. Server Logs - просмотр лог-файлов сервера (error log, slow query log, general query log).
3. Options File - графическое редактирование конфигурационного файла (my.cnf / my.ini), изменение параметров InnoDB, MyISAM, Networking и др.
4. System Profile - настройка профиля ОС управляемого сервера (тип ОС, путь к конфигу, команды старта/остановки). Без него остальные функции раздела недоступны.

Раздел «Performance» («Производительность») - мониторинг и анализ эффективности сервера. Основные пункты:
1. Dashboard - приборная панель с метриками в реальном времени:
   a. Network Status - сетевой трафик и подключения.
   b. MySQL Status - кэш таблиц, количество SQL-запросов в секунду.
   c. InnoDB Status - работа Buffer Pool, чтение/запись, doublewrite.
2. Performance Reports - готовые отчёты на базе Performance Schema (SYS):
   a. Statement Analysis - топ запросов по времени, задержкам, ошибкам; полное сканирование; временные таблицы.
   b. Schema Statistics - статистика по схемам и таблицам (I/O, блокировки).
   c. InnoDB Reports - Buffer Pool, I/O, статистика по схемам и таблицам.
   d. Memory Usage - потребление памяти по событиям, пользователям, хостам.
   e. Wait Events - события ожидания по пользователям и классам.
3. Performance Schema Setup - настройка Performance Schema: режим «Easy Setup» (включение всех инструментов) и расширенное управление инструментами и потребителями.

#### Задание 7
SQL-запрос, полученный с помощью кнопки “Export recordset to external file”:

```sql
CREATE TABLE `simpledb`.`resume` (
  `resumeid` INT NOT NULL AUTO_INCREMENT,
  `userid` INT NOT NULL,
  `title` VARCHAR(100) NOT NULL,
  `skills` TEXT NULL,
  `created` TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP(),
  PRIMARY KEY (`resumeid`),
  INDEX `userid_idx` (`userid` ASC) VISIBLE,
  CONSTRAINT `userid`
    FOREIGN KEY (`userid`)
    REFERENCES `simpledb`.`users` (`id`)
    ON DELETE CASCADE
    ON UPDATE CASCADE);
```

