## Задача 1
### Условие:
Определите адреса клиентов, заказывавших игры с доставкой.
### Ход решения:
Для решения задачи необходимо понять что мы должны получить в конце. В данном случае, в ответе мы должны получить таблицу содержащую только адреса клиентов которым требуется доставка.
Следовательно, нужно определить каким клиентам она требуется. Для этого мы соединим таблицы Заказ(предварительно оставив только колонки "ИД клиента" и "Получение") и Клиент(предварительно оставив только колонки "ИД клиента" и "Адрес"), а после сделаем выборку по условию "Доставка":
1. Проекция таблицы Клиент:
   
$$
КлиентNew = Клиент[idКлиент, Адрес]
$$

| idКлиент | Адрес                  |
| -------- | ---------------------- |
| К1       | ул. Пионерская, 26-58  |
| К2       | ул. Васи Зайцева, 14-6 |

2. Проекция таблицы Заказ:

$$
ЗаказNew = Заказ[Получение, Ид клиента]
$$

| Получение | Ид клиента |
| --------- | ---------- |
| Самовывоз | К1         |
| Самовывоз | К2         |
| Доставка  | К2         |

3. Соединение таблиц:

```SQL
Клиент_заказ = JOIN ЗаказNew ON КлиентNew.idКлиент = ЗаказNew.Ид клиента
```
<img width="459" height="138" alt="image" src="https://github.com/user-attachments/assets/3d126f1b-40ba-4379-b5f0-1eabe3793847" />


4. Выборка нужного:
```SQL
CREATE VIEW Клиенты_с_доставкой AS
SELECT * FROM simpledb.клиенты_с_заказами
WHERE `Получение` = 'Доставка';
```
<img width="483" height="64" alt="image" src="https://github.com/user-attachments/assets/7c263d3b-63a3-483a-a2f5-a9832f1814c5" />

5. Проекция нужного столбца:
```SQL
CREATE VIEW Адреса_доставки AS
SELECT Адрес FROM simpledb.клиенты_с_доставкой;
```

## Задача 2
### Условие:
Определите название и производителя игры (игр), в которую можно играть самой большой компанией.
### Ход решения:
Интуитивно хочется использовать MAX и решить задачу за один запрос. Но в нашем случае нужно дойти до решения только операциями реляционнной алгебры, поэтому такое решение не подойдёт.
Путём долгих поисков найден метод решения через "перемножение" таблицы саму на себя, дабы получить пары "каждая игра с каждой", после чего выделить те игры, для которых нет "более сильной" пары. Таким образом, нужно сделать следующие шаги:
1. Проекция Игр

```SQL
CREATE VIEW Игры_с_игроками AS
SELECT Название, Производитель, `Максимум игроков` FROM simpledb.Игра;
```
<img width="487" height="178" alt="image" src="https://github.com/user-attachments/assets/db2436f8-f441-45e6-8ca3-beaa4d9f05ab" />

2. Декартово произведение новой таблицы самой с собой

```SQL
CREATE VIEW Игры_с_игроками_2 AS
SELECT 
    x.Название      AS Название_x,
    x.Производитель AS Производитель_x,
    x.`Максимум игроков` AS Максимум_x,
    y.Название      AS Название_y,
    y.Производитель AS Производитель_y,
    y.`Максимум игроков` AS Максимум_y
FROM Игра AS x
CROSS JOIN Игра AS y;
```
<img width="835" height="449" alt="image" src="https://github.com/user-attachments/assets/371e507e-14c3-4266-939f-544e8962ab49" />

3. Делаем выборку пар игр, у которых максимум больше чем у каких-то других игр

```SQL
CREATE VIEW Игры_выигрывают AS
SELECT *
FROM игры_с_игроками_2 WHERE Максимум_x > Максимум_y;
```
<img width="838" height="101" alt="image" src="https://github.com/user-attachments/assets/c1368b29-2747-43ed-879a-63a58e70c116" />

Из этой выборки нам нужно обратить внимание на "y", так как именно там будут игры оказавшиеся слабее.

4. Делаем выборку по "y", отсеивая дубликаты

```SQL
CREATE VIEW Проигравшие AS
SELECT DISTINCT 
    Название_y      AS Название,
    Производитель_y AS Производитель,
    Максимум_y      AS `Максимум игроков`
FROM игры_выигрывают;
```
